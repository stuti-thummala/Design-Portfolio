# Product Design Portfolio

A clean, modern product design portfolio website featuring a navy blue and gold color palette with subtle bubbly aesthetic elements.

## Features

- **Responsive Design**: Fully responsive layout that works on all devices
- **Modern UI**: Clean and professional design with smooth animations
- **Navy Blue & Gold Theme**: Sophisticated color palette (#1a2332 navy blue, #d4af37 gold)
- **Bubbly Aesthetic**: Rounded corners, floating bubble animations, and smooth transitions
- **Sections**:
  - Hero section with animated background
  - Featured work showcase with project cards
  - About section with skills display
  - Contact section with social links

## Quick Start

Simply open `index.html` in a web browser to view the portfolio.

For local development with live reload:
```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.

## Technologies Used

- HTML5
- CSS3 (Custom Properties, Grid, Flexbox, Animations)
- Vanilla JavaScript (Intersection Observer API, Smooth Scrolling)

## Color Palette

- Navy Blue: `#1a2332`
- Light Navy: `#2a3444`
- Gold: `#d4af37`
- Light Gold: `#e5c766`

## Customization

To customize the portfolio:
- Edit content in `index.html`
- Modify colors in `styles.css` using CSS custom properties
- Adjust animations in `script.js`
